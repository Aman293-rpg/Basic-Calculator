
# 🧮 Basic Calculator

A simple, responsive, and user-friendly calculator built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations through a clean and intuitive interface.

## 🚀 Live Demo

🔗 **Live Demo:** [ GitHub Pages link here]

## 📌 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* % Percentage
* 🔢 Decimal calculations
* 🗑️ Clear display
* ⌫ Delete last character
* ⚡ Instant calculation
* 📱 Responsive and simple user interface

## 🛠️ Technologies Used

| Technology | Purpose                       |
| ---------- | ----------------------------- |
| HTML5      | Structure of the calculator   |
| CSS3       | Styling and responsive layout |
| JavaScript | Calculator functionality      |
